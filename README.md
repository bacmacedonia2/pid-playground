# PID Playground

A small static PID response simulator. It runs entirely in the browser; no backend or build step is needed.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `pid-playground` (or any name).
2. Upload `index.html` to the repository root and commit.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. Wait for deployment. The site URL will look like `https://YOUR-USERNAME.github.io/pid-playground/`.

For a user site repository named `YOUR-USERNAME.github.io`, the URL will instead be `https://YOUR-USERNAME.github.io/`.
